# RouterPlex

Multi-model LLM API gateway fronting 37 models from multiple vendors behind one API key and prepaid balance, exposing OpenAI-compatible and Anthropic-compatible REST endpoints, streaming, tool calling, JSON mode, vision, and image generation.

## APIs

- **RouterPlex Inference API** — OpenAI-compatible and Anthropic-compatible REST API for chat completions, model listing, and image generation across 37 models. Key-authenticated with per-key budgets, allowlists, and rate limits. (`https://api.routerplex.com/v1`)

> Publicly consumable REST API confirmed at https://api.routerplex.com/v1 (OpenAI-compatible) and https://api.routerplex.com (Anthropic-compatible, appends /v1/messages). Agent-native surfaces confirmed: llms.txt (https://routerplex.com/llms.txt), llms-full.txt (https://docs.routerplex.com/llms-full.txt), plus machine-readable Markdown companions at https://routerplex.com/pricing.md and https://routerplex.com/benchmarks.md. The provider's own apis.json at https://routerplex.com/apis.json was not fetchable during research and advertised a base URL (marketing host) that differs from the actual API host.

**Corrected 2026-08-09 by the enrichment pass.** Two claims in the July research were wrong:
>
> - **A real OpenAPI 3.1.0 IS published** — at `https://routerplex.com/openapi.json` (the marketing host root, not the docs host or the API host), served as `application/vnd.oai.openapi+json;version=3.1`. Five operations: `createChatCompletion`, `createImageGeneration`, `createCodexResponse`, `createMessage`, `listModels`. It is discoverable via an RFC 9727 API catalog at `https://routerplex.com/.well-known/api-catalog`, which names it as the `service-desc`. Harvested to `openapi/`.
> - **A hosted MCP server IS live** — at `https://routerplex.com/mcp`, anonymous and unauthenticated. `initialize` reports `routerplex-public-catalog` v1.0.0 on protocol `2025-06-18`; `tools/list` returns three read-only tools (`routerplex_list_models`, `routerplex_find_models`, `routerplex_get_api_reference`) with real inputSchemas. It is undocumented — absent from llms.txt, llms-full.txt, the sitemap and the api-catalog — and answers `GET` with 405 + `Allow: POST, OPTIONS`. Harvested to `mcp/`.
>
> Still absent as of 2026-08-09: no A2A agent card (`/.well-known/agent-card.json` and `/.well-known/agent.json` 404 on all three hosts), no security.txt, no status page, no changelog, no deprecation policy, no first-party SDKs or CLI, no OAuth, no event/webhook surface, and no published compliance program.
